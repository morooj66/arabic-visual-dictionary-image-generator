# Arabic Visual Dictionary Image Generation Experiment

This notebook is an experimental workflow for generating educational images for selected Arabic visual dictionary entries.

## Purpose

The goal of this notebook is to test image generation quality, prompt structure, and visual consistency using a limited sample of Arabic dictionary data.

It is not applied to the full dataset yet.

## What This Notebook Does

- Reads a selected sample of Arabic dictionary entries
- Uses the Arabic word, definition, word type, and avoid notes
- Builds a structured prompt for image generation
- Generates educational images using `gpt-image-1`
- Saves the generated images for review and comparison

## Current Status

This is an early testing version.  
The notebook currently works on selected entries only, not the complete dataset.

## Tools Used

- Python
- Jupyter Notebook / Google Colab
- OpenAI API
- gpt-image-1
- Pillow

## Notes

This notebook is part of the experimentation phase for an Arabic visual dictionary project.  
The purpose is to evaluate image quality and improve the prompt before scaling the process to the full dataset.
